# Helpdesk – AI Customer Support Ticket System (CODESPARK 2026)

Spring Boot 4.1.2 · Java 21 · MySQL 8 · Spring Data JPA · Spring Security

## Run
1. Copy `.env.example` to `.env` and set `DB_PASSWORD` to your MySQL root password.
2. Windows (PowerShell): `.\mvnw spring-boot:run`
3. Open http://localhost:8080/api/categories
